未签名 APK（unsigned.apk）。


说明 Tauri 已经成功完成了 Release 构建，但是还没有对 APK 进行数字签名。

Android 安装正式 APK 时需要有效签名，因此你需要给它签名后再安装。

## 一、生成 Android 签名密钥

先确保电脑安装了 JDK，然后在 PowerShell 执行：

```
keytool -genkeypair -v `
  -keystore release.jks `
  -alias tauri `
  -keyalg RSA `
  -keysize 2048 `
  -validity 10000
```

按照提示输入：

- Keystore 密码
- 姓名或组织信息
- 国家代码
- 确认信息

最后会生成：

```
release.jks
```

重要： 这个文件和密码一定要备份。以后更新同一个 Android 应用，需要继续使用兼容的签名密钥。

## 二、给现有 APK 签名

不需要重新编译，可以先给刚才生成的 APK 签名。

找到 Android SDK Build Tools 中的 `apksigner.bat`：

```
Get-ChildItem "$env:LOCALAPPDATA\Android\Sdk\build-tools" -Filter apksigner.bat -Recurse
```

假设找到的版本是 `35.0.0`，执行：

```
$APKSigner = "$env:LOCALAPPDATA\Android\Sdk\build-tools\35.0.0\apksigner.bat"

$UnsignedAPK = ".\src-tauri\gen\android\app\build\outputs\apk\universal\release\zlit-universal-release-unsigned.apk"

& $APKSigner sign `
  --ks ".\release.jks" `
  --ks-key-alias tauri `
  --out ".\app-release.apk" `
  $UnsignedAPK
```

执行时输入之前创建的 Keystore 密码。

## 三、验证签名

```
& $APKSigner verify --verbose ".\app-release.apk"
```

如果显示：

```
Verifies
```

说明签名成功。

## 四、安装到手机

手机开启 USB 调试，连接电脑：

```
adb devices
```

安装：

```
adb install -r .\app-release.apk
```



成功

&#x20;现在应该可以正常安装了。



## 五、让以后每次构建自动签名（推荐）

已按 Tauri 官方的 `keystore.properties` 方式配置完成，不需要每次手动执行 `apksigner`。

### 1. 创建 `src-tauri/gen/android/keystore.properties`

该文件已被 `src-tauri/gen/android/.gitignore` 忽略，不会提交到 Git：

```properties
password=你的密码
keyAlias=tauri
storeFile=../../../../release.jks
```

- `storeFile` 相对 `src-tauri/gen/android/app/` 解析，四个 `..` 回到项目根目录；也可以直接写绝对路径。
- store 密码与 key 密码使用同一个 `password` 值。

### 2. 修改 `src-tauri/gen/android/app/build.gradle.kts`

在文件顶部添加导入：

```kotlin
import java.io.FileInputStream
```

在 `buildTypes` 前添加：

```kotlin
signingConfigs {
    create("release") {
        val keystorePropertiesFile = rootProject.file("keystore.properties")
        val keystoreProperties = Properties()
        if (keystorePropertiesFile.exists()) {
            keystoreProperties.load(FileInputStream(keystorePropertiesFile))
        }

        keyAlias = keystoreProperties["keyAlias"] as String
        keyPassword = keystoreProperties["password"] as String
        storeFile = file(keystoreProperties["storeFile"] as String)
        storePassword = keystoreProperties["password"] as String
    }
}
```

在原来的 `buildTypes` 的 `release` 中添加：

```kotlin
getByName("release") {
    signingConfig = signingConfigs.getByName("release")
}
```

之后执行 `pnpm tauri android build` 生成的 release APK 会自动签名，无需再手动运行 `apksigner`。

验证签名配置：

```powershell
cd src-tauri\gen\android
.\gradlew.bat :app:signingReport
```

输出中 `universalRelease` 的 `Store` 指向 `release.jks`、`Alias` 为 `tauri` 即表示配置生效。

注意：`keystore.properties` 和 `release.jks` 都不要提交到 Git；换电脑或 CI 构建时重新生成该文件即可。

官方文档：[Tauri Android Code Signing](https://v2.tauri.app/distribute/sign/android/)
