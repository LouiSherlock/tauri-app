在 Tauri 2 + React + Android 的 Edge-to-Edge 模式下，状态栏高度不建议写死为 `24px` 或 `28px`。

应该通过 Android 原生 `WindowInsets` 获取真实高度，再让 React 使用 CSS 变量适配。

## 一、Kotlin 获取状态栏高度

在你的 Android 原生插件中增加一个命令：

```
@Command
fun getStatusBarHeight(invoke: Invoke) {
    activity.runOnUiThread {
        val insets = WindowCompat.getInsetsController(
            activity.window,
            activity.window.decorView
        )

        val rootInsets = androidx.core.view.ViewCompat
            .getRootWindowInsets(activity.window.decorView)

        val height = rootInsets
            ?.getInsets(
                androidx.core.view.WindowInsetsCompat.Type.statusBars()
            )?.top ?: 0

        val density = activity.resources.displayMetrics.density

        invoke.resolve(
            mapOf(
                "heightPx" to height,
                "heightDp" to height / density
            )
        )
    }
}
```

这里：

- `heightPx`：物理像素。
- `heightDp`：Android dp 单位。
- `top`：状态栏实际占用的顶部 Insets。

## 二、React 获取状态栏高度

创建 `src/services/system-bars.ts`：

```
import { invoke, isTauri } from '@tauri-apps/api/core';

interface SystemBarInfo {
  heightPx: number;
  heightDp: number;
}

export async function getStatusBarHeight() {
  if (!isTauri()) return 0;

  try {
    const info = await invoke<SystemBarInfo>(
      'plugin:system-bars|getStatusBarHeight'
    );

    return info.heightDp;
  } catch (error) {
    console.error('获取状态栏高度失败', error);
    return 0;
  }
}
```

## 三、设置 CSS 变量

在 `App.tsx` 或布局组件中：

```
import { useEffect } from 'react';
import { getStatusBarHeight } from '@/services/system-bars';

export function AppLayout() {
  useEffect(() => {
    getStatusBarHeight().then((height) => {
      document.documentElement.style.setProperty(
        '--status-bar-height',
        `${height}px`
      );
    });
  }, []);

  return (
    <div className="app-layout">
      <header className="app-header">
        Fitodo
      </header>

      <main>
        页面内容
      </main>
    </div>
  );
}
```

## 四、CSS 适配

```
:root {
  --status-bar-height: 0px;
  --navigation-bar-height: 0px;
}

.app-layout {
  min-height: 100dvh;
  padding-top: var(--status-bar-height);
}

.app-header {
  height: 56px;
}
```

如果使用 Tailwind：

```
<header className="pt-[var(--status-bar-height)]">
  ...
</header>
```

注意： 这里选择了让整个布局避开状态栏的普通内容布局。如果你的页面背景需要延伸到状态栏后面，应该只给 Header 内部内容添加顶部 padding，而不是给整个页面添加。

## 六、特别提醒

Android 状态栏高度可能因为以下因素变化：

- 刘海屏、挖孔屏。
- 横竖屏切换。
- 系统显示缩放。
- 沉浸式模式。
- Android 系统版本。

因此建议使用 `WindowInsets`，不要使用固定高度。

把状态栏、导航栏、刘海屏安全区域统一封装成一个 `useSystemInsets()` Hook，统一管理 `top / bottom / left / right` 四个方向，后续页面不需要再关心 Android 原生细节。
