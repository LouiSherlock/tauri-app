针对 React + Vite + Tauri 2 项目，采用 Edge-to-Edge（边到边）布局：

- 页面背景一直延伸到屏幕最底部，包括手势条和三键导航区域。
- 顶部内容避开状态栏。
- 底部 TabBar 背景延伸到导航区域，图标和按钮不会被遮挡。
- 同时兼容全面屏手势导航和传统三键导航。
- 不依赖固定的 `24px`、`48px` 等设备尺寸。

最重要的是：系统导航区域的背景由 Android 窗口控制，Web 页面负责内容布局，两者需要配合。

2. WebView：允许页面绘制到系统栏后方。

## 二、Android 原生配置

这是关键步骤。仅设置 CSS 不够，因为 Android 需要先允许 WebView 延伸到系统导航栏后面。

### 1. 找到 MainActivity.kt

通常位于：

```
src-tauri/
└── gen/
    └── android/
        └── app/
            └── src/
                └── main/
                    └── java/
                        └── ...
                            └── MainActivity.kt
```

你的文件可能类似：

```
package com.example.app

import app.tauri.TauriActivity

class MainActivity : TauriActivity()
```

保留原来的 `package` 声明。

### 2. 修改 MainActivity.kt

将内容改为：

```
package com.example.app

import android.graphics.Color
import android.os.Build
import android.os.Bundle
import app.tauri.TauriActivity
import androidx.core.view.WindowCompat
import androidx.core.view.WindowInsetsControllerCompat

class MainActivity : TauriActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // 允许内容绘制到状态栏、导航栏后面
        WindowCompat.setDecorFitsSystemWindows(window, false)

        // 状态栏和导航栏透明
        window.statusBarColor = Color.TRANSPARENT
        window.navigationBarColor = Color.TRANSPARENT

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            // 关闭系统自动添加的导航栏对比遮罩
            window.isNavigationBarContrastEnforced = false
            window.isStatusBarContrastEnforced = false
        }

        // 设置系统图标颜色
        val controller = WindowInsetsControllerCompat(
            window,
            window.decorView
        )

        // 浅色背景使用深色图标
        controller.isAppearanceLightStatusBars = true
        controller.isAppearanceLightNavigationBars = true
    }
}
```

这里有几个重要配置：

| 配置                                        | 作用            |
| ----------------------------------------- | ------------- |
| `setDecorFitsSystemWindows(false)`        | 允许内容绘制到系统栏后面  |
| `statusBarColor = TRANSPARENT`            | 状态栏透明         |
| `navigationBarColor = TRANSPARENT`        | 导航栏透明         |
| `isNavigationBarContrastEnforced = false` | 取消系统导航栏自动对比遮罩 |
| `isAppearanceLightNavigationBars = true`  | 使用深色导航按钮或手势条  |

如果你的应用是深色背景，把两个 `isAppearanceLight...` 设置为 `false`。

Android 15 起，Target SDK 35 及以上会强制 Edge-to-Edge；Android 官方也建议通过 WindowInsets 处理系统栏遮挡。

.app-content {
  flex: 1;

  overscroll-behavior: contain;

/* 底部导航栏 */

  padding-bottom: var(--safe-bottom);

  background: #ffffff;

  border-top: 1px solid #eeeeee;
}

/* 主体内容不要被底部导航遮挡 */

注意这里没有给整个 `body` 添加底部 padding，因为我们希望背景延伸到手势条下面，而不是让整个页面缩小。

## 四、兼容不同 Android WebView 版本：原生 Insets 桥接

这里我建议你额外做一步。

Android WebView 的 CSS `env(safe-area-inset-bottom)` 并不是所有版本都能可靠获取：

- WebView M136：支持安全区域 Insets，但仅限全屏 WebView。
- WebView M144：扩展到所有 WebView。
- 更旧版本：可能返回 `0px`。

Tauri 使用设备系统提供的 Android WebView，不会随 APK 一起打包固定版本。

[image](https://www.google.com/s2/favicons?domain=https://developer.android.com\&sz=32)

Android Developers+1



因此，为了兼容更多手机，我们可以通过 Android 原生 `WindowInsets` 获取真实高度，再传递给 React。

### 1. 扩展 MainActivity.kt

在前面的 `MainActivity` 中添加以下 import：

```
import android.view.View
import android.view.ViewGroup
import android.webkit.WebView
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat
```

在 `onCreate()` 的系统栏配置后面添加：

```
setupSafeAreaBridge()
```

然后在 `MainActivity` 类中添加两个方法：

```
private fun setupSafeAreaBridge() {
    val contentView = findViewById<View>(android.R.id.content)

    ViewCompat.setOnApplyWindowInsetsListener(contentView) { view, insets ->

        // 获取状态栏、导航栏、刘海屏安全区域
        val safeInsets = insets.getInsets(
            WindowInsetsCompat.Type.systemBars() or
            WindowInsetsCompat.Type.displayCutout()
        )

        // Android 像素转换成 CSS 使用的 dp
        val density = resources.displayMetrics.density

        val top = safeInsets.top / density
        val bottom = safeInsets.bottom / density
        val left = safeInsets.left / density
        val right = safeInsets.right / density

        // 同步到 WebView
        view.post {
            findWebView(view)?.evaluateJavascript(
                """
                (() => {
                    const root = document.documentElement;

                    root.style.setProperty(
                        '--native-safe-area-top', '${top}px'
                    );

                    root.style.setProperty(
                        '--native-safe-area-bottom', '${bottom}px'
                    );

                    root.style.setProperty(
                        '--native-safe-area-left', '${left}px'
                    );

                    root.style.setProperty(
                        '--native-safe-area-right', '${right}px'
                    );
                })();
                """.trimIndent(),
                null
            )
        }

        // 不消费 Insets，继续传递给子 View
        insets
    }

    ViewCompat.requestApplyInsets(contentView)
}

private fun findWebView(view: View): WebView? {
    if (view is WebView) {
        return view
    }

    if (view is ViewGroup) {
        for (i in 0 until view.childCount) {
            val result = findWebView(view.getChildAt(i))

            if (result != null) {
                return result
            }
        }
    }

    return null
}
```

这样 Android 原生层会在系统 Insets 变化时，把真实的安全区域高度同步到 WebView。

注意：这里的实现假定 Tauri 的 WebView 已经挂载在 `android.R.id.content` 下。如果你的 Tauri 版本调整了原生视图层级，需要相应调整 WebView 查找方式。

### 2. 修改 CSS，使用原生 Insets 优先兜底

把之前的变量定义替换成：

```
:root {
  --safe-top: max(
    env(safe-area-inset-top, 0px),
    var(--native-safe-area-top, 0px)
  );

  --safe-bottom: max(
    env(safe-area-inset-bottom, 0px),
    var(--native-safe-area-bottom, 0px)
  );

  --safe-left: max(
    env(safe-area-inset-left, 0px),
    var(--native-safe-area-left, 0px)
  );

  --safe-right: max(
    env(safe-area-inset-right, 0px),
    var(--native-safe-area-right, 0px)
  );
}
```

现在安全区域有两个数据来源：

1. WebView 原生 CSS `env()`。
2. Android Kotlin `WindowInsets`。

两者取较大值，避免部分 WebView 返回 `0px` 的问题。

## 五、完整目录结构

最终建议整理成这样：

```
tauri-app/
├── index.html
├── src/
│   ├── App.tsx
│   ├── main.tsx
│   └── styles/
│       └── safe-area.css
│
└── src-tauri/
    ├── Cargo.toml
    ├── tauri.conf.json
    └── gen/
        └── android/
            └── app/
                └── src/main/java/
                    └── .../
                        └── MainActivity.kt
```



特别注意：

- 不要使用固定的 `padding-bottom: 24px`。
- 不要给 `body` 统一设置底部留白。
- 不要把 `touch-action: none` 用在整个页面上。
- 不要在 Android 原生层和 CSS 层重复添加同一份 padding。
- 如果重新执行 `tauri android init`，注意备份自己修改过的 Kotlin 文件。
